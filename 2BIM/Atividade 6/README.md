# 🟢 Atividade 6 – Navegação Interna

**Tema:** Âncoras e Navegação Interna  
**Objetivo:** Criar uma página com links internos que rolam até partes específicas da mesma página.  

Nesta atividade foi criada uma página com três seções:
- Início  
- Sobre  
- Contato  

Os links utilizam o atributo `href="#id"` para navegar internamente dentro do mesmo documento.

**Arquivo principal:** `navegacao.html`
