# 🟢 Atividade 2 – Organização de Dados

**Tema:** Organização de Dados  
**Objetivo:** Entender e aplicar a estrutura de tabelas no HTML.  

Nesta atividade foi criada uma tabela com 3 colunas e 5 linhas usando as tags:
- `<table>` para estruturar a tabela;  
- `<tr>` para criar as linhas;  
- `<th>` para os títulos das colunas;  
- `<td>` para os dados de cada célula.

**Arquivo principal:** `minha-tabela.html`
