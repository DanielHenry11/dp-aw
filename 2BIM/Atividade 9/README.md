# 🟡 AM4 – Estilizando Formulários

## 🎯 Tema: CSS em Formulários
O CSS melhora a aparência e usabilidade dos formulários, destacando campos e botões com estilos visuais agradáveis.

---

## 💡 Objetivo
Aplicar **CSS externo** para estilizar um formulário de contato com foco em:
- Espaçamento entre campos e seções;
- Cores e bordas personalizadas;
- Efeitos de interação com `:hover` e `:focus`.

---

## 🧱 Estrutura do Projeto
**Arquivos:**
- `form-estilizado.html` — estrutura do formulário;
- `form.css` — estilos aplicados.

---

## 🎨 Recursos usados
- Layout centralizado;
- Transições suaves nos inputs;
- Efeito de foco nos campos (`:focus`);
- Botão com hover estilizado.
