# 🔴 Atividade 5 – Página Institucional

**Tema:** Estrutura Completa de Site  
**Objetivo:** Criar uma página institucional com estrutura semântica e estilização com CSS externo.  

Nesta atividade foi criada uma página modelo de empresa contendo:
- Estrutura semântica com `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>`;  
- Navegação entre seções simulada;  
- Estilos visuais aplicados em um arquivo CSS externo (cores, fontes e espaçamentos).

**Arquivos principais:**
- `pagina-institucional.html`
- `style.css`
