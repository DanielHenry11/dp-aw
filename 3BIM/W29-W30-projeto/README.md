# Projeto III — Responsividade Avançada

## Auditoria Lighthouse

### Performance
1. Imagens grandes — convertidas para WebP.
2. CSS excessivo — otimizado.
3. Renderização bloqueada — estrutura ajustada.

### Acessibilidade
1. Foco invisível — corrigido com :focus.
2. Inputs sem label — corrigidos.
3. Baixo contraste — cores ajustadas.
