## Atividade 1 — Estruturando Cabeçalho e Rodapé

Nesta atividade foi criada a estrutura básica de uma página HTML utilizando as tags
semânticas `<header>`, `<main>` e `<footer>`.  
O cabeçalho contém o nome do site e uma navegação simples, o corpo possui um texto de exemplo,
e o rodapé apresenta os créditos da página.
