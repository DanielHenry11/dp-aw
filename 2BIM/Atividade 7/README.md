# 🟢 Atividade 7 – Página com Seções Semânticas

**Tema:** HTML Semântico  
**Objetivo:** Aplicar as principais tags semânticas em uma página estruturada.  

Nesta atividade foi criada uma página de exemplo contendo:
- `<header>` e `<footer>` para o cabeçalho e rodapé;
- `<main>` como conteúdo principal;
- `<section>` para agrupar notícias;
- `<article>` para cada conteúdo individual;
- `<aside>` com informações adicionais.

**Arquivo principal:** `semantica.html`
