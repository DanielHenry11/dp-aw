# 🟡 Atividade 4 – Formulário de Contato

**Tema:** Coleta de Informações  
**Objetivo:** Criar um formulário simples para o envio de dados.  

Nesta atividade foi criado um formulário contendo:
- Campo de nome (`<input type="text">`);
- Campo de e-mail (`<input type="email">`);
- Campo de mensagem (`<textarea>`);
- Botão de envio (`<button>`).

**Arquivo principal:** `form-contato.html`
