# 🟡 AM3 – Formulário de Cadastro Completo

## 🎯 Tema: Tipos de Campos em Formulários
Os formulários no HTML permitem coletar diferentes tipos de informações do usuário, como texto, e-mail, opções e seleções.  
Nesta atividade, o objetivo foi criar um **formulário de cadastro completo** com diversos tipos de campos.

---

## 💡 Objetivo
Criar um formulário que permita ao usuário preencher seus dados e selecionar preferências, aplicando corretamente as tags de formulário.

---

## 🧱 Estrutura do Projeto
**Arquivo:** `cadastro.html`  
**Conteúdo:**  
- Campos de texto: nome, e-mail, senha, cidade;  
- Campo de seleção (`<select>`) com estados;  
- Botões de opção (`<input type="radio">`) para gênero;  
- Caixas de seleção (`<input type="checkbox">`) para interesses;  
- Estilos básicos com CSS interno para melhor apresentação.
