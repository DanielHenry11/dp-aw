# 🟡 Atividade 3 – Tabela de Horários

**Tema:** Tabelas Avançadas  
**Objetivo:** Criar uma tabela mais complexa utilizando as tags de estrutura e células unidas.  

Nesta atividade foi criada uma tabela de horários usando:
- `<thead>`, `<tbody>` e `<tfoot>` para organizar o conteúdo;  
- `rowspan` para unir células na vertical;  
- `colspan` para unir células na horizontal.  

**Arquivo principal:** `tabela-horarios.html`
